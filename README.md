# PluMail Android

Application Android officielle de PluMail.

## Objectif de cette première version

Cette première version de l’application Android PluMail a pour objectif principal d’améliorer le parcours utilisateur.

L’application permet d’accéder plus simplement aux services PluMail depuis un téléphone Android, sans obliger l’utilisateur à ouvrir manuellement un navigateur externe.

## Fonctionnement

L’application reste basée sur le webmail PluMail.

Elle affiche l’interface web de PluMail directement dans une application Android dédiée. Il ne s’agit donc pas encore d’un client mail natif complet, mais d’une interface mobile légère permettant d’accéder plus facilement au webmail, à la connexion et au parcours d’inscription.

## Accès aux services

PluMail reste accessible de plusieurs manières :

- depuis un navigateur web ;
- via les protocoles standards IMAP / SMTP ;
- via cette application Android ;
- via l’APK direct disponible dans les releases GitHub ;
- via Google Play.

## Pourquoi une application Android ?

L’objectif est de proposer un accès plus simple pour les utilisateurs moins techniques.

Beaucoup d’utilisateurs ne souhaitent pas configurer manuellement un client mail avec IMAP/SMTP. Cette application permet donc d’avoir un accès rapide et clair aux services PluMail, tout en conservant les accès standards existants.

## Respect des standards

L’application Android ne remplace pas les standards ouverts.

Les utilisateurs peuvent toujours utiliser PluMail avec un navigateur, un client mail compatible IMAP/SMTP ou tout autre outil compatible avec les standards de messagerie.
